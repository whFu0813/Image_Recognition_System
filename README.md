# 图像识别系统 (Image Recognition System)

基于 Python + OpenCV + PyQt5 开发的图像处理与识别系统，支持图像分割、Mask生成、目标抠图、贴纸拖动等功能。

## 📦 功能特性

### 图像输入
- 支持从文件读取图像（JPG、PNG、BMP）
- 支持摄像头实时预览与抓拍

### 图像分割
- **阈值分割**：基于二值化的目标区域提取
- **边缘检测**：基于 Sobel 算子的边缘提取
- **区域分割**：基于连通域分析的区域提取

### 形态学处理
- 腐蚀（Erosion）
- 膨胀（Dilation）
- 开运算（Opening）
- 闭运算（Closing）
- 可调核大小参数

### Mask 编辑
- **反转 Mask**：对生成的二值Mask进行反转操作
- **去除小区域**：基于连通域分析，仅保留最大目标区域
- **绘制蒙版**：手动绘制/擦除Mask区域，支持笔刷大小调节和撤销操作

### 目标编辑
- **目标抠图**：将背景替换为白色
- **导出透明背景**：导出为带Alpha通道的PNG图像
- **替换背景**：选择新背景图进行替换
- **模糊背景**：对背景区域进行高斯模糊（突出目标）
- **贴纸拖动**：将抠出的目标作为贴纸拖动到任意位置，支持旋转和缩放

### 特征测量
- 面积测量
- 周长测量
- 重心计算

## 🎯 使用流程

1. **加载图像**
   - 点击「打开图像」选择本地图片
   - 或点击「打开摄像头」进行实时预览并抓拍

2. **生成 Mask**
   - 在「分割方式」下拉框中选择分割算法（阈值分割/边缘检测/区域分割）
   - 点击「生成 Mask」按钮

3. **编辑 Mask（可选）**
   - 使用「Mask编辑」功能优化Mask：反转Mask、去除小区域
   - 点击「背景处理」→「绘制蒙版」手动修正Mask

4. **目标处理**
   - 点击「应用目标抠图」查看抠图效果
   - 或选择「背景处理」中的替换背景、模糊背景、贴纸拖动

5. **特征测量**
   - 生成Mask后点击「特征测量」查看目标区域的面积、周长、重心

6. **导出结果**
   - 点击「保存结果」保存处理后的图像
   - 或点击「导出透明背景图像」导出PNG格式

## 📝 核心算法说明

### 区域分割
GUI中使用的是**连通域分析**（Connected Component Analysis），通过 `cv2.connectedComponents` 提取图像中的连通区域，并保留面积最大的区域作为目标。代码中也实现了**区域生长算法**（Region Growing），从种子点开始根据灰度值相似性逐步扩展区域。

### 边缘检测
使用 Sobel 算子计算水平和垂直方向的梯度，通过梯度幅度提取图像边缘。

### 形态学操作
基于结构元素的图像变换，包括腐蚀、膨胀、开运算、闭运算，用于去除噪声、填充空洞、连接邻近区域等。

## 🖼️ 界面布局

主窗口采用三栏布局：
- **左栏**：原图显示区域
- **中栏**：Mask图/分割结果显示区域，包含显示方式切换
- **右栏**：处理结果显示区域
